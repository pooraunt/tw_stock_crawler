# tw_stock_crawler

台股資料爬蟲：從證交所、櫃買中心、公開資訊觀測站等來源爬取資料，清理後存入 `db/` 的 SQLite。
每種資料一支爬蟲模組（`.py`），GUI 介面集中在 `main_twstock_crawler.pyw`（唯一入口）。

## 合作方式

- **先討論，使用者說「開始」才動手。** 在那之前只做唯讀的事（讀檔、`SELECT`、少量試抓網址），不建立、不修改任何檔案與資料庫。使用者只回答部分問題時，剩下的再問一次，不要自行假設後開工。
- **不動舊程式，另外生成新檔。** 這個資料夾不是 git 倉庫，覆寫就沒有備份。
  要讓使用者比較兩種版本時，存成另一個檔名。
- **資料不輕易刪。** 資料表、資料庫、舊檔要刪或要搬都先問；退役的程式移到 `old_data/`，不直接刪除。
- **不確定就問**，尤其是欄位要不要留、資料代表什麼意思。
- **回報要老實**：開頭先說做了什麼、沒動什麼；測試結果附數字；沒測到的部分明講
  （例如「GUI 只確認能開啟，沒有實際按開始」）。
- 回覆使用繁體中文。

## 不要碰

- `db/` 的正式資料庫：測試一律用暫存資料庫或副本，查詢用唯讀方式開啟
  （`sqlite3.connect('file:db/x.db?mode=ro', uri=True)`）。
- 全市場的完整爬取（常需數十分鐘）留給使用者從 GUI 執行，不要代跑。

## 依據

- 本檔位於 `.claude/`，下列路徑與指令皆以專案根目錄為基準。
- 資料怎麼清理：[docs/通用資料清理規則.md](../docs/通用資料清理規則.md)，每次寫爬蟲前重讀。
  遇到規則沒涵蓋的情況先問，同意後在對應章節新增條文並登記於「規則異動紀錄」。
- 新增、重構、修改爬蟲：使用 `tw-crawler-dataset` skill。
- 修改 `main_twstock_crawler.pyw`：使用 `tw-crawler-gui` skill。

## 環境

- Windows、Python 3.14、pandas 3.0、requests 2.34。
- 執行 GUI：`pythonw main_twstock_crawler.pyw`；各爬蟲可單獨以文字介面執行：`python daily_price.py`。
- 各爬蟲的執行訊息由 `log_common` 寫入 `log/*.log`；主程式另以 `logging` 把未處理的例外寫入 `log/main_error.log`（`.pyw` 沒有主控台，錯誤只會出現在這裡）。各爬蟲模組不另用 `logging`。
- 程式內的註解、docstring、log 訊息一律用繁體中文，寫法與現有模組一致。
